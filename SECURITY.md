# Security

GridLens is a static website with no backend, no accounts and no user data.

Please report vulnerabilities privately through
[GitHub's private vulnerability reporting](https://github.com/open-energy-transition/gridlens/security/advisories/new),
not in a public issue. We aim to reply within a week.

In scope: the website and its build and deploy workflows, and the issue
automation described in `CONTRIBUTING.md` (for example, issue text that
makes the agent act beyond the approved task).
